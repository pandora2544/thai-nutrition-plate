# จัดจานอาหารตามวัย (Thai Nutrition Plate) — เวอร์ชันทดลอง

เว็บสำหรับนักศึกษาวิชาโภชนาการฝึกออกแบบอาหาร: เลือกกลุ่มวัย → จัดจานรายมื้อ (กรอกเป็น g/ml หรือ kcal) → สรุปทั้งวันเทียบเกณฑ์

- โปรเจกต์นี้แยกจากระบบอื่นทั้งหมด ไม่แก้ "ค้นอาหารและสารอาหาร" รุ่น 1.1.3 ของอาจารย์ (ใช้สำเนาข้อมูลเท่านั้น)
- ไม่มีเซิร์ฟเวอร์ ไม่ส่งข้อมูลที่กรอกออกจากเครื่อง; หลังเปิดครั้งแรกใช้งานแบบออฟไลน์ได้
- ไม่มีข้อมูล ≠ 0: ยอดรวมบอกจำนวนรายการที่ขาดข้อมูลเสมอ

## สถานะ
เวอร์ชันทดลอง: เปิดใช้ "หญิงตั้งครรภ์ ไตรมาส 2" และ "หญิงให้นมบุตร 0–5 เดือน" ด้วยเกณฑ์จากใบงานชุด A (24 พ.ย. 2569) ซึ่งอ้าง Thai DRI 2563
กลุ่มอื่นรอถอดตาราง Thai DRI 2563 หน้า 439–441 · ภาพวัตถุดิบรอตรวจลิขสิทธิ์และความถูกต้อง
แบบระบบฉบับเต็มอยู่ในโปรเจกต์ Nutrition App
