# จัดจานอาหารตามวัย — ไฟล์สำหรับ WU eLearning (เวอร์ชันทดลอง)

แบบฝึกออกแบบมื้ออาหารสำหรับนักศึกษาวิชาโภชนาการ ทำงานต่อจาก "ค้นอาหารและสารอาหาร" รุ่น 1.1.3 และใช้ฐานอาหาร 822 ระเบียนชุดเดียวกัน

1. เลือกกลุ่มวัยตามเกณฑ์ Thai DRI 2563 (31 กลุ่ม รวมหญิงตั้งครรภ์ไตรมาส 1–3 และหญิงให้นมบุตร)
2. หยิบวัตถุดิบใส่จาน (แบบร้านค้าออนไลน์) โดยกรอกปริมาณเป็นกรัมหรือเป็นกิโลแคลอรีก็ได้ จานแสดงเป็นภาพสามมิติ
3. ดูสรุปทั้งวัน แล้วเทียบกับเป้าหมายของกลุ่มวัย

## เปิดใช้

`Thai_Nutrition_Plate_Offline.html` เป็นไฟล์เดียวที่มีฐานข้อมูล เกณฑ์ DRI และภาพวัตถุดิบอยู่ข้างใน
- ไม่ต้องใช้บัญชี Google และไม่ต้องใช้ API key
- ไม่ต้องต่ออินเทอร์เน็ต
- ข้อมูลที่นักศึกษากรอกจะไม่ถูกส่งออกจากเครื่อง

ถ้าเปิดไฟล์จากเครื่องตัวเอง ให้ดาวน์โหลดแล้วเปิดด้วย Chrome, Edge, Firefox หรือ Safari หน้าตัวอย่าง HTML ในแชตหรือในโปรแกรมอ่านไฟล์อาจไม่รันโปรแกรม

## นำขึ้น WU eLearning (Moodle)

1. เข้ารายวิชา แล้วเปิดโหมดแก้ไข
2. เพิ่มแหล่งข้อมูลชนิด **ไฟล์ (File)** แล้วอัปโหลด `Thai_Nutrition_Plate_Offline.html`
3. ในส่วนการแสดงผล (Appearance) ให้เลือกเปิดในหน้าต่างใหม่หรือเปิดเต็มหน้า เพราะการฝังในกรอบเล็กจะทำให้จานและรายการวัตถุดิบแคบ
4. บันทึก แล้วลองเปิดด้วยบัญชีนักศึกษาทดสอบ นักศึกษาจะเข้าผ่านรหัสนักศึกษาและ WU Pass ตามปกติของระบบ eLearning

ถ้าระบบปฏิเสธไฟล์ HTML หรือขนาดไฟล์เกินกำหนด ให้ใช้ลิงก์เว็บแทนได้:
https://pandora2544.github.io/thai-nutrition-plate/
โดยเพิ่มแหล่งข้อมูลชนิด **URL** ทั้งไฟล์และลิงก์ให้ผลเหมือนกัน

## ข้อควรทราบ

- งานที่จัดไว้ถูกเก็บในเบราว์เซอร์ของเครื่องนั้น หากล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง งานจะหายไป ให้นักศึกษาพิมพ์หรือคัดลอกสรุปก่อนส่ง
- ค่าเป้าหมายจาก Thai DRI 2563 หน้า 439–442 ผ่านการถอดค่ารอบแรก ผู้สอนควรตรวจทานซ้ำก่อนใช้จริง
- ค่าที่มีป้าย "ค่าฝึกในใบงาน" เป็นค่าฝึกตามใบงาน ไม่ใช่ค่า DRI
- สารอาหารที่ฐานข้อมูลไม่มีค่า จะไม่ถูกนับเป็นศูนย์ และระบบจะแสดงว่า "ยังยืนยันไม่ได้"
- ภาพวัตถุดิบ 77 รายการเป็นภาพประกอบที่สร้างด้วย Gemini ใช้เพื่อให้จำวัตถุดิบได้ ไม่ใช่ภาพขนาดหนึ่งส่วนบริโภคจริง อาหารที่ยังไม่มีภาพใช้ภาพลายเส้นแทน

## สร้างไฟล์ใหม่หลังแก้ข้อมูล

```
python3 tools/build_offline.py
```
คำสั่งนี้รวมไฟล์เว็บ ฐานอาหาร และภาพ เป็น `dist/Thai_Nutrition_Plate_Offline.html` และ `dist/Thai_Nutrition_Plate_eLearning.zip`
